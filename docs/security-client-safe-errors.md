# Client-safe assessment errors

The public workspace reports outcomes, not infrastructure implementation.

- Before run creation: explain that the service is not ready and confirm that no assessment began.
- After run creation: explain that status is temporarily unavailable and confirm that the exact run is preserved.
- Actual stage failure: explain that the assessment requires attention and preserve completed evidence.

Raw database, volume, backend-origin, and route details remain available only through authorized diagnostics and release evidence.
