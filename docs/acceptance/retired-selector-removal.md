# Retired selector removal acceptance

The public NICO workspace exposes one canonical Strategic assessment. Production acceptance treats either of these states as valid:

- the retired Express/Comprehensive selector is absent from the rendered workspace; or
- the selector remains attached only as a fully hidden compatibility control.

Visible or partially hidden legacy tier controls remain a release failure. This contract does not change exact-SHA binding, two-pass execution, human review, or blocked client delivery requirements.
