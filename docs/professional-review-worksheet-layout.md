# Professional review worksheet layout

The active polished renderer consumes the existing eight-section
`v5.substantive_review_sections` projection unchanged. It renders each supplied
field and item, in order, with no additional PDF-only item caps, character cuts,
or shrink-to-fit frames. This does not expand the authoritative projection or
claim to include evidence outside it.

Single-column paragraphs use 9pt or larger embedded fonts. Sections flow
naturally; continuation pages repeat their section ID and localized title.
Every page retains automated-draft, pending-human-decision and blocked-delivery
boundaries. Reviewer/date/evidence lines and decision choices remain present.

Page totals are measured after rendering. Installer metadata does not claim a
fixed four-page companion or two sections per page when the flowing renderer is
active. Final composition retains its existing 60-page boundary and rejects
unpreservable content rather than cutting or shrinking worksheets.

Literal markup is escaped. Accented Spanish and supported Unicode punctuation
are retained. A glyph unavailable in the bundled font causes an explicit error
naming its Unicode code point; it is not silently replaced with a missing-glyph
box. Supporting further scripts requires an appropriate portable font.

Synthetic fixtures and visual inspections establish layout behavior, not the
new page count of a retained production report. That count requires a replay.
