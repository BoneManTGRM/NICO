## Evidence and coverage contract

Free-form supplied evidence, its collection status, date, supplier and transport
digest never establish runtime execution or independent verification. Literal
values and provenance remain unchanged in the human evidence appendix/JSON/CSV.
The existing `production_acceptance` projection can establish an observation only
by referencing a `retained_runtime_executions` record with actual/performed kind,
matching repository/commit/scope, timestamp, evidence reference and retained results.
Independent review must identify a different reviewer, a later timestamp, an
evidence reference and the SHA-256 of that exact execution object. Bare legacy
status claims remain unverified. These are report projection tests, not claims
that a new execution or specialist-review service has been implemented.

Phase3 requires explicit complete substantive coverage, full-coverage claim and
completed specialist review for functional QA, parity, requirements, stakeholder
alignment, roadmap and staffing. Missing or partial dimensions mean LIMITED;
section processing is separately reported. Operator approval cannot satisfy them.

New canonical sources carry `nico.report_truth.v2`. Changes require a newly
reviewed edition. Existing authorized receipts, bytes and source certificates are
not migrated or reissued. Actual transmission remains separately false unless a
supported delivery action records it; this mission authorizes no transmission.
