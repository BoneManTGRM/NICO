# Acceptance criteria

- Canonical technical and evidence-adjusted score aliases agree.
- A matching 92/86 score pair cannot produce `canonical_evidence_adjusted_score_mismatch`.
- A completed exact-SHA Bandit run cannot remain in `incomplete_analyzers`.
- Equivalent summary and detailed complexity records collapse to one canonical finding.
- The stated unique-finding count equals the deduplicated register count.
- Known broken identifiers are repaired in Markdown and HTML.
- Human review remains required and client delivery remains blocked.
- Targeted regression tests and the complete required-check suite pass.
